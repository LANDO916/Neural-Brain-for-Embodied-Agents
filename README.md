# Orpheum Dream Engine

A minimal, mysterious audio-to-visual dream generator powered by LLMs.

## Quick Start

```bash
# Clone repository
git clone https://github.com/yourusername/orpheum-dream-engine.git
cd orpheum-dream-engine

# Setup environment
cp .env.example .env
# Edit .env with your OpenAI API key

# Install
pip install -r requirements.txt

# Run
python -m orpheum.engine
```

## Features

- Minimal, mysterious interface
- Real-time audio analysis
- LLM-powered interpretation
- Abstract visualizations
- Neural activity indicators

## Architecture

The system processes audio through a pipeline of neural nodes:

- **ING**: Ingestion and preprocessing
- **ANA**: Analysis and feature extraction
- **CRE**: Creative synthesis
- **PER**: Persona council
- **REA**: Reality manifestation

Each node uses AI to understand and transform the audio into visual parameters.

## Usage

1. Open http://localhost:5000
2. Click "LOAD AUDIO"
3. Select an audio file
4. Watch the dream unfold
